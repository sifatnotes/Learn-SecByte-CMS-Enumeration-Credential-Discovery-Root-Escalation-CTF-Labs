# Learn SecByte CMS Enumeration, Credential Discovery & Root Escalation CTF Labs

A focused collection of **cybersecurity labs, CTF labs, hands-on cybersecurity labs, ethical hacking labs, and penetration testing labs** from Learn SecByte.

This collection emphasizes CMS-focused reconnaissance and security concepts, including **CMS enumeration, password discovery, configuration analysis, credential discovery, user enumeration, credential reuse, pivoting, sudo privilege escalation, and CMS-to-root CTF scenarios**.

The labs are useful for cybersecurity students, CTF players, pentesters, SOC analysts, and security learners practicing in authorized environments.

## How to Use the Labs

1. Select a lab from the collection.
2. Read the lab instructions and identify the objective.
3. Work only against the authorized CTF environment.
4. Begin with systematic reconnaissance.
5. Record discovered applications, users, configurations, credentials, and other findings.
6. Document the reasoning behind each step.
7. Review the security impact of each technique after completing the lab.

Skills represented across this collection include:

- CMS enumeration
- Web reconnaissance
- User enumeration
- Configuration analysis
- Credential discovery
- Credential reuse
- Linux privilege escalation
- Sudo security
- Root escalation concepts
- Pivoting
- CTF methodology
